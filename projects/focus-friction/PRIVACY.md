# Privacy Notes

Focus Friction is designed to be local-first.

## Stored locally

- blocklist
- focus preferences
- schedule
- temporary unlock expiry
- typed intentions
- emergency bypass reasons
- basic aggregate counters

## Not transmitted

This version contains no server endpoint, analytics SDK, telemetry API, account system or remote database.

## Why this matters

A productivity tool can easily become surveillance software. This project intentionally avoids collecting the user's browsing history on a remote server.

## Safety boundary

Focus Friction is a productivity tool. It is not a medical device, diagnostic system or clinical treatment for ADHD.
